# 青葉テクノロジー 来客受付

本社1階の受付で使う来客アプリです。ロビーのタッチ画面で来客自身が受付し、受付デスクでスタッフがご案内と退館を記録します。

## できること

- **来客画面** (`/`): ご予約の呼び出し、アポイントのない来客、お荷物・配達の受付。完了すると受付番号のカードが出ます。
- **受付デスク** (`/desk`): ロビー待ち、ご案内中、来訪予定、退館を見ながら、受付・ご案内・退館・連絡済みを記録します。
- 記録は `data/reception.json` に残り、画面を閉じても当日の来客は残ります。デスクの「デモを初期状態に戻す」でサンプルに戻せます。

初回表示には、本日のサンプル来客が入っています。山田太郎さんなど、予約名の一部を入れると呼び出しできます。

## 起動

```bash
npm install
npm run dev
```

開発サーバーは [http://localhost:3000](http://localhost:3000) です。来客画面が開きます。受付デスクは `/desk` です。
