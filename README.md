# 株式会社ライトパス 来客受付

本社1階の受付で使う来客アプリです。最初の画面にタッチすると用件を選び、記入が終わると担当者の連絡先へ連絡が届きます。

## できること

- **来客画面** (`/`): 画面にタッチすると、「来客用」「面接用」「配送・工事用」から選べます。
  - **来客用**: 会社名、訪問者の名前、誰に対してのアポかを記入します。選んだ担当者の連絡先へ連絡します。
  - **面接用**: 訪問者の名前だけ記入します。人事担当（鈴木 陽子）の連絡先へ連絡します。
  - **配送・工事用**: 「配送」または「工事・作業」を選ぶと、記入なしで総務担当（渡辺 彩）の連絡先へ連絡します。
- **担当者への連絡** (`/phone`): 受付から送った連絡を、担当者ごとに確認できます。連絡先が携帯なら携帯の画面、WowTalkならWowTalkとして届きます。
- **受付デスク** (`/desk`): ロビー待ち、ご案内、退館を記録できます。担当者の連絡先はここで変更でき、携帯かWowTalkを選べます。WowTalkのIDは空欄のままあとから設定できます。

連絡先は画面上のものです。実在の電話番号やWowTalkへは発信しません。

記録は `data/reception.json` に残り、画面を閉じても当日の来客は残ります。デスクの「デモを初期状態に戻す」でサンプルに戻せます。

## 起動

```bash
npm install
npm run dev
```

開発サーバーは [http://localhost:3000](http://localhost:3000) です。来客画面が開きます。担当者の携帯は `/phone`、受付デスクは `/desk` です。
